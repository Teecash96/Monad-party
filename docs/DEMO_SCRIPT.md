# Three minute demo

## 0:00 to 0:25

Open the landing page. State the rule in one sentence: complete the featured game milestone on two different UTC days and connect X.

Show the live countdown and current pool.

## 0:25 to 0:55

Open Passport. Connect the demo wallet. Show the first game stamp and the return day stamp. Open Connect, link X, sign the ownership message, complete OAuth, and return to the app.

Return to Passport. Show the completed game milestone, second active day, current X verification, and unlocked weekly entry.

## 0:55 to 1:30

Open Admin with the owner wallet. Fund the demo epoch with a small test amount.

Show the published Merkle root and its IPFS snapshot. Explain that every public entry has only an index, wallet address, and proof. X profile data stays private.

## 1:30 to 2:05

Request the draw after the epoch delay. Open the transaction in MonadVision.

Show the Pyth Entropy request and callback. Show the three distinct winner indexes and the 50, 30, 20 amounts.

## 2:05 to 2:40

Switch to one winning wallet. Open Claim. Enter the epoch. Fetch its proof and submit the claim.

Show the confirmed transfer. Then show that a second claim or a proof from another wallet fails.

## 2:40 to 3:00

Open Winner History. Show the root, eligible count, winners, and claim status.

Close with the core value: repeat play becomes a public, verifiable, sponsor funded reward loop.
